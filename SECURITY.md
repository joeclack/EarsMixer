# Security policy

## Scope

Report vulnerabilities affecting the local mixer server, browser mixer, admin dashboard and desktop installers. Include the affected release, build, deployment or commit where known.

## Reporting a vulnerability

Use **Report a vulnerability** on [GitHub Security Advisories](https://github.com/joeclack/EarsMixer/security/advisories) if private reporting is available. Otherwise, contact the maintainers privately at `support@earsmixer.app` to arrange a secure way to share details. Keep vulnerability details out of public issues, pull requests and discussions.

Include the affected component, observed behaviour and impact. Sanitise evidence and remove credentials, mixer PINs, session tokens, private network details and personal data. Coordinate disclosure with the maintainers while they investigate.
